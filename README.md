# ОБОД — веломастерская в Санкт-Петербурге

Учебный сайт-визитка по заданию №2. Мастерская вымышленная. Цель посетителя — выбрать услугу, узнать ориентировочную цену и описать проблему в учебной форме.

## Запуск
В архиве откройте index.html в современном браузере; в исходном репозитории страница находится в dist/index.html. Установка, npm, сборка и сервер не нужны. Для GitHub/GitVerse Pages можно перенести содержимое dist в корень репозитория и включить Pages. Файлы: index.html, style.css, main.js, assets/*.svg. JS подключён с defer, пути относительные.

## Дизайн
Яркое розово-лавандовое стекло, серебро и голубые переливы. Полупрозрачные панели, размытый фон и тонкие светлые границы объединяют шапку, кнопки, услуги, галерею и форму. Салатовый акцент удалён. Нумерации секций нет.
Локальный NauryzRedKeds для всех заголовков, Manrope для основного текста. Для загрузки нужен интернет, предусмотрены системные fallback-шрифты.
Колёса вращаются средствами CSS; кнопка с паузой останавливает оба. При prefers-reduced-motion вращение и плавная прокрутка отключены.

## Функции
- Семантические header, nav, main, section, article, figure, address, footer; Grid и Flexbox.
- Обычные якоря с плавной прокруткой; prefers-reduced-motion отключает плавность.
- Три услуги, стандартное модальное окно dialog/showModal: закрытие кнопкой и Escape, возврат фокуса, выбор услуги в форме.
- Имя, email, услуга, сообщение: связанные label, обязательность, ошибки у полей, aria-invalid, переход к первой ошибке. Одни пробелы не принимаются. Введённые данные сохраняются.
- Учебный режим: submit отменён через preventDefault; запросы не отправляются, данные не сохраняются. Успех: «Данные проверены. Это учебное демо: заявка не отправлена».
- Три изображения в галерее, прозрачные велосипед и хромированный логотип на первом экране. При ошибке загрузки — текстовая замена. Галерея не управляется JavaScript: при удалении её элементов остальная страница работает.

## Контакты и публикация
Адрес района, примерные цены, почта .example и нулевой телефон — демонстрационный контент, требующий замены перед реальным запуском. VK не ведёт на чужой аккаунт. В учебной версии контакты помечены явно. Приватная публикация предназначена для просмотра владельцем; для сдачи преподавателю потребуется доступная ему публикация Pages и ссылка на репозиторий.
